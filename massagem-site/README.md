# 🌸 Site Profissional de Massoterapia

Este é um projeto de **Landing Page** desenvolvido para a apresentação de serviços de massagem profissional. O objetivo principal é oferecer uma interface elegante, intuitiva e funcional para que clientes possam conhecer os tratamentos disponíveis e realizar agendamentos de forma rápida.

---

## 🚀 Funcionalidades

- **Apresentação de Serviços:** Listagem detalhada dos tipos de massagem oferecidos.
- **Design Responsivo:** Interface otimizada para visualização em computadores, tablets e smartphones.
- **Sistema de Agendamento:** Integração com banco de dados local para registro de solicitações.
- **Foco em Conversão:** Chamadas para ação (CTAs) estratégicas para facilitar o contato da cliente.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de front-end e gestão de dados leve:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização personalizada para uma experiência visual relaxante e profissional.
- **SQLite:** Utilizado para o gerenciamento e armazenamento local dos agendamentos realizados pelo site.

---

## 📂 Estrutura do Repositório

Conforme a organização atual do projeto:

- `index.html`: Arquivo principal contendo a estrutura da página.
- `estilo.css`: Folha de estilo responsável pelo design visual.
- `agendamentos.sqlite`: Base de dados para persistência das marcações de clientes.
- `LICENÇA`: Termos de uso e distribuição do código.
